> [!TIP]
> **你是否有过这样的烦恼？**
> - Windows 的屎山代码太多，Explorer动不动就爆炸。
> - Explorer一爆，还得自己 Ctrl+Shift+Esc 调出任务管理器重新启动Explorer。

### 难道，就没有什么软件来解决这一点吗？

***Expreload***，专为屎山Explorer而生。

- 但检测到Explorer停止运行超过十秒，自动弹窗询问是否重启Explorer。
- 提供 Ctrl+Shift+E 一键重启 Explorer
